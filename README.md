# BLUE SPEED — Personal Website

Website profil pribadi bertema **Fast & Furious / automotive** dengan palet Baby Blue, Sky Blue, putih, dan navy. Mobil dan foto profil menggunakan gambar yang diberikan untuk proyek ini.

## Isi folder

```text
blue-speed-website/
├── index.html
├── README.md
└── assets/
    ├── images/
    │   ├── skyline-avatar.png   # Foto mobil dan avatar untuk bagian Home
    │   └── profile-beach.jpg    # Foto profil untuk bagian About Me
    └── js/
        └── script.js           # Tahun footer dan penanda menu aktif
```

## Cara menjalankan

1. Ekstrak file ZIP.
2. Buka folder `blue-speed-website`.
3. Klik dua kali `index.html` atau buka melalui browser.
4. Pastikan folder `assets` tetap berada satu tingkat dengan `index.html` agar gambar dan JavaScript dapat dimuat.

Website tidak membutuhkan instalasi package atau koneksi internet untuk menjalankan fitur dasarnya.

## Cara publikasi melalui GitHub Pages

1. Buat repository baru di GitHub.
2. Unggah seluruh isi folder ini (bukan hanya `index.html`) ke root repository.
3. Buka **Settings → Pages**.
4. Pada bagian Build and deployment, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.
6. Tunggu proses publikasi selesai. Buka URL GitHub Pages yang ditampilkan GitHub.
7. Pastikan repository bersifat public jika menggunakan pengaturan GitHub Pages yang mensyaratkannya.

## Bagian yang perlu dilengkapi

Di `index.html`, ganti placeholder berikut dengan data pribadi sebelum dikumpulkan:

- `[YOUR NAME]` — nama lengkap.
- `[YOUR NIM]` — nomor induk mahasiswa.
- `[Add your hobbies and personal interests here.]` — hobi/minat.
- `[YOUR EMAIL / INSTAGRAM]` — kontak atau media sosial (opsional).

Periksa kembali informasi pribadi sebelum repository dipublikasikan. Jangan unggah data sensitif yang tidak diperlukan.

## Teknologi

- HTML5
- CSS3 (ditulis di dalam `index.html`)
- JavaScript vanilla (`assets/js/script.js`)

## Catatan aset

Gambar di folder `assets/images` adalah foto yang disertakan dalam proyek. Konsep otomotif terinspirasi dari film Fast & Furious; website ini merupakan proyek personal/nonresmi dan tidak berafiliasi dengan pemilik waralaba tersebut.
